# E-commerce Project

A full-stack e-commerce web application built with Django (backend) and React (frontend).

## Tech Stack

- Frontend: React, Tailwind CSS, Axios (for API calls)
- Backend: Django, Django REST Framework
- Database:  PostgreSQL
- State Management: React Context API
- Storage: localStorage (for cart)

## Features

- Product listing
- Product details page
- Add to cart
- Remove from cart
- Increase / decrease quantity
- Cart total count
- Total price calculation
